해결 방식

버튼을 없애는 것이 아니라 버튼을 찾아다닐 필요를 줄이고, 사용자가 듣기 어려워하면 말하는 방식도 바꾼다.

Voice-first, not Voice-only

조회·추가·수정·삭제·확인 등 핵심 주문 흐름은 음성으로 수행하고, 확인과 복구는 큰 글씨 화면이 함께 도와줍니다. 한 번의 충분한 발화는 항목별로 다시 묻지 않습니다.

Adaptive TTS Level 0–2

"다시 말해줘", "천천히 말해줘"라는 명시적 요청에 따라 발화 속도와 문장 분절이 단계적으로 적응합니다.

주문은 두 종류입니다.
아메리카노. 두 잔.
총 금액은 9,400원입니다. Level 2 안내 예시

안전한 주문 상태

인식 실패나 모호한 요청이 곧바로 오주문으로 이어지지 않습니다. 검증된 장바구니는 보호되고, 잘못 반영한 직전 변경은 되돌릴 수 있습니다.

서비스 화면

큰 글씨와 최소한의 조작으로 구성된 Minimal GUI입니다.

시스템 구조

클라우드 의존 없이 로컬에서 동작하는 파이프라인입니다. NLU는 주문 상태를 직접 바꾸지 않으며, 결정론적 Order Engine만 검증된 주문을 실행합니다.

  1. 사용자 발화마이크 입력 · VAD 종료 감지
  2. STTwhisper-medium QLoRA 도메인 학습
  3. NLU발화를 OrderCommand[]로 구조화
  4. Order Engine메뉴 DB 검증 후 장바구니 반영
  5. Adaptive TTSMeloTTS 친절체 · Level 0–2
  6. 응답음성 안내 + 큰 글씨 화면
