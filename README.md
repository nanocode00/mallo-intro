# Mallo 소개 페이지

말로(Mallo)는 시각·터치 중심 키오스크 이용에 부담을 느끼는 고령 사용자를 위한 Voice-first 대화형 카페 주문 시스템입니다.

- `/`: 서비스 소개와 기술 소개를 선택하는 랜딩 페이지
- `/customer/`: 고객·일반 사용자를 위한 서비스 소개
- `/developer/`: 개발자·평가자를 위한 기술 소개

배포 URL: <https://nanocode00.github.io/mallo-intro/>

빌드 과정 없이 GitHub Pages에서 제공하는 정적 HTML/CSS 사이트입니다.
